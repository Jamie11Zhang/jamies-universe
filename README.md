# Jamie's Universe ✨

A cosmic sketchbook personal site — a stick-figure Jamie floating through a hand-drawn, blue-hued universe.

**Sections:** 🪐 Projects · 🌍 Life · 👾 About

Built with HTML, CSS, vanilla JS, and [Rough.js](https://roughjs.com/) for the hand-drawn doodles.

## View it live

Enabled via GitHub Pages: https://jamie11zhang.github.io/jamies-universe/

## Run locally

Just open `index.html` in any browser.
